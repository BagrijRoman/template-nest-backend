# Backend Application — Feature List

Atomic feature breakdown of the delivered work, one estimable unit per row. Swagger documentation is part of each endpoint's row. Tests are work too: every feature with tests is followed by its own `Tests: <feature>` row stating the test type (unit / e2e) and what is covered.
